# Demo 用照片

| 檔案 | 用途 |
|---|---|
| `f-1-paigu-bento.jpg`、`f-2-veg-bento.jpg`、`f-3-greens.jpg`、`f-4-guabao.jpg` | 和種子 `seed/images/` 相同：重置示範資料後，`f-1`～`f-4` 自動有照片。要示範「先拍照再上架」時，也可以把這幾張放進模擬器相簿當作拍到的照片 |
| `left-at-door.jpg` | 志工回報「放門口」時必須附照片：先放進模擬器相簿（`adb push left-at-door.jpg /sdcard/Pictures/`），回報時從相簿選 |

都已壓到 800px、200 KB 以內（後端上限 `IMAGE_MAX_BYTES`）。來源與授權見 `data/SOURCES.md`。`f-5` 保久乳、`f-6` 鮪魚罐頭沒有照片：團隊提供的是網路商品圖，有品牌與版權問題，沒有放進來，要的話請自己拍。
