# T-115 據點與食物點改用臺北市開放資料

> 2026-11-07｜合約 [11-meal-relay.md](../system/11-meal-relay.md) v2.2 §3、§4、§10｜issue #51

比賽規則要求核心資料用開放資料並註明來源。T-115 把種子 `seed/stations.json`、`seed/points.json` 裡估算的據點與食物點，換成臺北市開放資料裡的真實機構與地點。資料在開發時下載、手動挑選後寫進種子 JSON；**執行時不連網**，也沒有新增任何抓資料的程式。

## 1. 用到的資料集

全部在 2026-11-07 從臺北資料大平台下載。授權都是**政府資料開放授權條款第 1 版**（data.gov.tw 上標示「政府資料開放授權條款-第1版」）。

| 臺北市銀髮族服務_社區照顧關懷據點 | 臺北市政府社會局 | https://data.gov.tw/dataset/121285 | `d082dc87-d3fd-479d-89c6-745ff1be955a` | `11930dc6-4092-4bde-a42c-7722e0416462` | `st-1`、`st-2`、`p-1`～`p-3` 的名稱與地址 |
| 臺北市各級學校分布圖(含國小.國中.高中職.特教學校.市立大專院校) | 臺北市政府教育局 | https://data.gov.tw/dataset/121225 | `58b4f7b9-d0c5-4de8-aa7f-981fcb625e45` | `28c5792b-3af6-4bff-8ad8-f5b5e53d4062` | `p-4` 的名稱與地址 |

- 登記在 `services/web/src/features/meal-relay/index.ts` 的 `sources`（顯示在 App 的「資料來源」頁）與 [data/SOURCES.md](../../data/SOURCES.md)。
- 社區照顧關懷據點、學校兩個資料集**只有地址、沒有座標**。座標一律查同為開放資料的「臺北市門牌位置數值資料」（民政局，每月更新，TWD97 TM2 座標），再換成 WGS84 經緯度。**沒有用 Google Maps、Nominatim 或任何地理編碼服務**，所以不涉及 ODbL。
- 找不到臺北市「里辦公處位置」的開放資料集（data.gov.tw 以「里辦公處」「里長」搜尋，只有嘉義、桃園、高雄等縣市）。社區照顧關懷據點資料集裡有不少里辦公處本身就是據點，`p-3` 就取自其中一筆。
- 種子的 `source` 欄位寫資料集名稱：名稱、地址來自第一個資料集，座標來自門牌資料時，寫成「臺北市銀髮族服務_社區照顧關懷據點、臺北市門牌位置數值資料」。學校資料集名稱很長，`source` 寫簡稱「臺北市各級學校分布圖」，完整名稱在 `sources` 與 SOURCES.md。

## 2. 挑了哪幾筆、為什麼

行政區一律萬華區（行政區代碼 `63000070`）。挑選依據是 `elders.json`（模擬長者，不能改）裡的位置：

- `st-1` 的 9 位長者（`e-1`～`e-8`、`e-10`）在龍山寺、康定路一帶，平均位置約 (25.0366, 121.5009)。
- `st-2` 的 3 位長者（`e-9`、`e-11`、`e-12`）在青年公園北側、中華路二段一帶，平均位置約 (25.0249, 121.5072)。

所以據點分別挑**離這兩群長者平均位置最近**的社區照顧關懷據點；里辦公處、學校挑 `st-1` 這群附近的；自訂點挑萬華區的固定里民活動場所，位置接近原本的估算點（萬華車站、西門）。

欄位對應：

| 種子欄位 | 社區照顧關懷據點 | 各級學校分布圖 | 固定里民活動場所 |
|---|---|---|---|
| `name` | `據點名稱`（原文照抄） | `schoolname` | `里別` + 「固定里民活動場所」 |
| `lat`、`lng` | `地址` → 門牌資料的 `橫座標`、`縱座標` → WGS84 | `address` → 同左 | `座標X`、`座標Y` → WGS84 |
| `kind` | `station`；里辦公處是 `village_office` | `school` | `custom`（提供者自己設的點，沿用原本的 `created_by`） |
| `source` | 資料集名稱 | 資料集名稱 | 資料集名稱 |

- 據點只用公開的機構名稱與機構地址，**沒有放電話、聯絡人**（原始資料有 `電話` 欄位，不使用）。
- 座標取到小數 6 位。門牌座標是門牌點，不是建築物中心；據點在樓上的（例如艾馨在 6 樓）也只記門牌位置。
- id、`checkin_code`（`MR7Q4KX2`、`MR3HV9PD`）、`kind`、`created_by` 都沒改，`foods.json`、`accounts.json`、`elders.json` 的引用不受影響。

## 3. 以後怎麼更新

不在 repo 裡放下載程式。要更新時照下面做，把結果手動改進 `seed/stations.json`、`seed/points.json`，**id 和 `checkin_code` 保持不變**：

```bash
# 1. 下載（社區照顧關懷據點約 510 筆、學校約 283 筆、里民活動場所約 270 筆；門牌 CSV 約 125 MB）
curl -sL "https://data.taipei/api/v1/dataset/11930dc6-4092-4bde-a42c-7722e0416462?scope=resourceAquire&limit=1000" -o care.json
curl -sL "https://data.taipei/api/v1/dataset/28c5792b-3af6-4bff-8ad8-f5b5e53d4062?scope=resourceAquire&limit=1000" -o school.json
curl -sL "https://data.taipei/api/v1/dataset/bf098ea3-c42e-4a41-b058-bc17b3d3ed46?scope=resourceAquire&limit=1000" -o place.json
curl -sL "https://data.taipei/api/dataset/b7c8e724-1e98-45ee-a0bd-f3840623ed97/resource/ce76ca0c-7f94-4935-ab47-1d2a41ca2abb/download" -o addr.csv

# 2. 找萬華區的那幾筆，確認名稱、地址還在
grep -o '"據點名稱":"[^"]*","據點類型":"[^"]*","地址":"臺北市萬華區[^"]*"' care.json
grep -o '"schoolname":"老松國小","postalcode":"[^"]*","address":"[^"]*"' school.json

# 3. 在門牌資料找地址（萬華區代碼 63000070；欄位依序是 街路段,地區,巷,弄,號；
#    數字是全形，段寫成國字，例如「中華路二段」「５０４巷」「４３號」）
grep "63000070,.*,康定路,,,,２２９號," addr.csv | head -1
grep "63000070,.*,中華路二段,,５０４巷,,４３號," addr.csv | head -1
```

4. 把 TWD97（`橫座標`、`縱座標`，TM2、中央經線 121°E、尺度 0.9999、東偏移 250000 公尺）換成 WGS84 經緯度。用任何開源工具都可以，例如 `pyproj`：`Transformer.from_crs("EPSG:3826", "EPSG:4326", always_xy=True).transform(x, y)` 回傳 `(lng, lat)`。T-115 用的是同一組參數的 TM 反算公式（純數學，不連網），並用 `pyproj` 的 EPSG:3826 → EPSG:4326 驗算過這 6 筆。另外拿里民活動場所資料自帶的座標和門牌座標比對同一地址（仁德里西寧南路192之2號），兩者差約 4 公尺。
5. 跑後端測試：`cd services/backend; uv run python -m pytest -q`（`test_seed_meets_contract_minimums`、`test_seed_is_idempotent`、`test_reset_demo_restores_seed_state` 要通過）。
6. 已經有資料的資料庫（例如 Render）啟動時不會重新匯入種子；要換成新座標，請管理員執行一次 `POST /demo/reset`（§10）。

## 4. 和模擬資料的界線

| 真實（開放資料） | 仍是模擬（畫面標示「模擬」） |
|---|---|
| 據點 `st-1`、`st-2` 的名稱與位置；食物點 `p-1`～`p-6` 的名稱與位置 | 長者（`elders.json`：稱呼、座標、過敏原，ADR-024） |
| | 食物（`foods.json`）、提供者（`suppliers.json`）、帳號（`accounts.json`） |

- 真實的據點、里辦公處、學校**沒有參與本服務**；種子只借用它們的公開名稱與位置做 Demo，不代表這些機構提供或領取食物。
- 據點帳號的顯示名稱在 `accounts.json`（`u-st-1`「艋舺社區關懷據點（模擬）」、`u-st-2`「青年公園社區關懷據點（模擬）」），不在 T-115 範圍內，沒有跟著改名。
