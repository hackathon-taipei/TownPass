# T-109 食物點、食物、庫存去向與圖片（後端 meal_food）

## 1. 說明
提供者（店家/機構）管理其食物點、上架食物、維護即時庫存去向（剩餘、派出中、已送達），以及食物圖片與現場照片之處理。

## 2. 實作範圍
- `services/backend/src/townpass_backend/features/meal_food/__init__.py`：匯出 router
- `services/backend/src/townpass_backend/features/meal_food/api.py`：8 個 HTTP 端點與角色依賴注入
- `services/backend/src/townpass_backend/features/meal_food/service.py`：業務邏輯、過敏篩選、庫存份數校驗、圖片解析
- `services/backend/tests/test_meal_food.py`：完整測試案例

## 3. 端點清單

| 端點 | 方法 | 權限角色 | 說明 |
|---|---|---|---|
| `/meal-relay/points` | GET | supplier, admin | 查詢食物點，支援 category 與 for_elder 排除過敏 |
| `/meal-relay/points` | POST | supplier (approved) | 新增自訂食物點 |
| `/meal-relay/foods` | GET | supplier, admin | 查詢食物清單，mine=1 時僅列出自己食物 |
| `/meal-relay/foods/{id}` | GET | supplier, volunteer, admin | 查詢特定食物資訊 |
| `/meal-relay/foods` | POST | supplier (approved) | 上架食物，驗證有效期限在未來 |
| `/meal-relay/foods/{id}` | PATCH | supplier (approved, owner) | 修改份數、有效期限、下架狀態；M14 防呆（份數不可小於已派送與送達數） |
| `/meal-relay/images` | POST | supplier, volunteer | 上傳 Base64 格式圖片，限制格式與 200KB 上限 |
| `/meal-relay/images/{id}` | GET | 公開（不需 Token） | 二進位圖片串流回應 |

## 4. 驗收項目與測試對照

| 驗收代碼 | 規則描述 | 測試案例 (test_meal_food.py) |

| V6 | for_elder 排除過敏衝突食物 | `test_v6_filter_allergens_for_elder` |

| V21 | 修改份數小於已派出加已送達 -> 409 QTY_BELOW_USED | `test_v21_patch_food_qty_below_used` |

| 圖片 | 格式與大小限制檢查、公開讀取 | `test_upload_and_get_image`, `test_image_too_large`, `test_image_invalid_mime` |
