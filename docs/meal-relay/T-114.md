# T-114 鄰食轉運站共用元件（MR-C01～MR-C06）與 `logic/shared.ts`

第 2 波頁面（T-116～T-120）共用的功能元件，對齊合約 [11-meal-relay.md](../system/11-meal-relay.md) **v2.2**。
能包 UI kit（[ui-kit.md](ui-kit.md)，MR-C07～C23）的就包，不重做。元件都**不呼叫 API**，只收 props、發 emit；頁面用 `data/` 取資料後傳進來。
型別與函數從 `logic/shared.ts` 匯入（ui/ 不能匯入 `data/`，check-arch W1）。

## 1. 元件

| 編號 | 元件 | 用途 | 包了哪個 kit 元件 | 用在哪一頁 |
|---|---|---|---|---|
| MR-C01 | `AllergenChecklist` | 過敏原勾選＋已選摘要 | MR-C20 AllergenChips | 提供者上架（MR-P06）、管理員登記長者（MR-P08） |
| MR-C02 | `LocationPicker` | 在地圖上點一下選位置 | MR-C07 MapView | 提供者新增食物點（MR-P06）、管理員登記長者（MR-P08） |
| MR-C03 | `FoodCard` | 一批食物：剩餘／派出中／已送達、最晚食用時間、狀態、無人認領提醒，加上修改與下架 | MR-C14 FoodRow | 提供者庫存（MR-P06）、管理系統（MR-P08） |
| MR-C04 | `ElderStatusTag` | 長者警示標籤：需要送餐／需要關懷／從未見到（M10） | — | 志工任務（MR-P05）、管理員名冊（MR-P08） |
| MR-C05 | `StaleBanner` | 斷網時顯示上次更新時間，提醒送出鍵停用（ADR-024） | `fade-up` 轉場 | 所有頁面最上方 |
| MR-C06 | `ImageInput` | 拍照或選圖，前端壓縮成 base64（M19） | `fade-up` 轉場 | 提供者上架（MR-P06，T-127 起是上架表單的第一步）、放門口照片（MR-P05） |

### Props／emit

| 元件 | props | v-model／emit | 備註 |
|---|---|---|---|
| AllergenChecklist | `label?`（預設「過敏原（可複選）」）、`hint?` | `v-model: Allergen[]` | 下方顯示「已選 N 項：花生、芒果」，沒選時「沒有過敏原」 |
| LocationPicker | `markers?: Marker[]`（參考用，預設 `[]`）、`center?: Location`、`label?`（沒選時的提示）、`disabled?` | `v-model: Location \| null` | 選了顯示座標（5 位小數）與「清除」；`disabled` 時只顯示、不能點選 |
| FoodCard | `food: Food`、`now: number`（頁面每秒更新）、`actions?`（預設 false） | `@edit(id)`、`@close(id)`；預設插槽 | `actions` 且食物是 `open`／`claimed` 時才有「修改」「下架」 |
| ElderStatusTag | `elder: Pick<Elder, 'meal_due' \| 'care_due' \| 'last_seen_at'>` | — | 沒有標籤時顯示「狀況正常」 |
| StaleBanner | `staleAt?: string \| null`（`Cached<T>` 的 `stale_at`）、`now: number` | — | `staleAt` 為空時不顯示 |
| ImageInput | `label?`（預設「拍照或選圖」）、`disabled?`、`previewUrl?: string \| null` | `@change({ data, mime: 'image/jpeg', bytes })`、`@clear()` | `data` 已去掉 `data:` 前綴，直接給 `uploadImage`；`@clear` 時父層要把 `previewUrl` 設成 `null` |

### 使用範例

```vue
<StaleBanner :stale-at="foods.stale_at" :now="now" />

<AllergenChecklist v-model="form.allergens" hint="沒有就不用選" />
<LocationPicker v-model="form.location" :markers="nearbyPoints" />
<ImageInput :preview-url="photoUrl" :disabled="saving" @change="onImage" @clear="photoUrl = null" />

<FoodCard v-for="f in foods" :key="f.id" :food="f" :now="now" actions @edit="openEdit" @close="closeFood" />
<ElderStatusTag :elder="task.elder" />
```

改份數用 kit 的 MR-C11 QtyInput：`<QtyInput v-model="qty" :min="food.dispatched_qty + food.delivered_qty" />`（M14）。

## 2. `logic/shared.ts`

| 函數／常數 | 用途 |
|---|---|
| `foodQtyText(food)` | 「剩 2／派出中 2／已送達 1」（M1，沿用 `foodQty.ts` 的欄位順序） |
| `countdownText(iso, now)` | 到某個時間還剩多久，沿用 `mealLabels.ts` 的 `timeLeftText`；已過或格式錯誤是「已到期」 |
| `homeRouteOf(role)` | 首頁「進入」的路由名稱：volunteer → `volunteer`、supplier → `supplier`、station → `station`；citizen、admin 回 `null`（留在首頁） |
| `elderTagsOf(elder)`、`ELDER_TAG_LABEL` | 長者警示標籤（M10），固定順序：需要送餐、需要關懷、從未見到 |
| `staleText(staleAt, now)` | 斷網提示文字：「目前離線，顯示的是 5 分鐘前的資料，暫時不能送出」 |
| `IMAGE_MAX_BYTES`、`IMAGE_MAX_EDGE`、`IMAGE_MIMES`、`isImageMime`、`fitSize`、`base64Bytes`、`IMAGE_QUALITY_STEPS` | 圖片壓縮（M19）：長邊 ≤ 800px、≤ 200000 bytes，依序試 JPEG 品質 0.85、0.7、0.55、0.4 |
| `foodPhotoOf(food)`、`FoodPhoto` | 食物照片（M19，T-127）：有 `image_url` 回 `{ src, alt }`，`src` 用 `imageSrc()` 轉成完整網址、`alt` 是食物名稱（空的才用「食物照片」）；沒照片回 `null`，畫面不顯示 |
| 轉出 | 型別 `Allergen`、`Cached`、`Elder`、`Food`、`IsoDateTime`、`Location`、`Role`；`mealLabels.ts` 的全部內容；`foodQty.ts` 的 `FOOD_QTY_FIELDS`、`foodQtyCounts` |

測試：`services/web/tests/meal-relay-shared.test.ts`（每個函數都有）。

## 3. 決策

| # | 決定 | 原因 |
|---|---|---|
| 1 | MR-C01 直接包 MR-C20 AllergenChips | kit 決策 10：兩者用途相同，不做兩套晶片 |
| 2 | `shared.ts` 轉出 `mealLabels.ts`，不搬移、不刪 | `mealLabels.ts` 是 kit 的檔案（不在本工單範圍）；頁面一律從 `shared.ts` 匯入，之後整理時再把內容搬進來 |
| 3 | ImageInput 一律輸出 JPEG | 照片用 JPEG 最省；透明 PNG 先鋪白底再轉，避免變黑底 |
| 4 | LocationPicker `disabled` 時也隱藏「清除」 | 只顯示的模式不該改值 |
| 5 | 據點 QR 倒數（MR-P07）與任務卡（MR-P05）不在這裡 | 工單規定由 T-119、T-118 自己做 |
