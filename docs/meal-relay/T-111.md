# T-111：長者名冊與拜訪回報

本套件提供管理員維護模擬長者名冊，以及志工回報派送任務拜訪結果的後端端點。長者不是帳號；資料只包含代號、座標與過敏原，不存姓名、電話或地址文字（ADR-024、ADR-026）。

## 端點

| 方法與路徑 | 角色 | 行為與合約 |
|---|---|---|
| `GET /meal-relay/elders` | admin | 回傳未合併長者名冊，依 M13 排除 `merged_into` 有值的資料。 |
| `POST /meal-relay/elders` | admin | 建立長者並直接回傳 `Elder`；`station_id` 必填、`created_by` 使用管理員帳號 id。M12 不做附近重複提示。 |
| `PATCH /meal-relay/elders/{id}` | admin | 更新有提供的代號、位置、過敏原、據點與下次時間。 |
| `POST /meal-relay/visits` | volunteer | 先由共用 `ensure_assigned_elder()` 確認本人仍有該長者的 `assigned` 任務，再依 M9、M11 更新拜訪、長者、申請；拜訪後由 M18 完成任務。 |

所有端點透過 `meal_router("meal_elder")` 掛載，使用 `X-Demo-User` 與共用角色檢查。業務錯誤依 §7 回傳 `{detail: {code, message}}`。未授權角色回 `FORBIDDEN_ROLE`；非本人任務長者回 `NOT_OWNER`。放門口回報須為送餐且附照片，否則分別回 `VALIDATION_ERROR`／`PHOTO_REQUIRED`；生鮮蔬果不可放門口，回 `FRESH_CANNOT_LEAVE`。
